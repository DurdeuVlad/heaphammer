# Temporary Planning & Scratchpad (`.scratch/`)

This directory is reserved for temporary planning documents, task-breakdown scratchpads, exploratory issue plans, and active agent execution notes.

---

## Guidelines
- **Transient Status**: Documents in this folder are working drafts and are **not** part of the permanent open-source documentation published in [`docs/`](../docs).
- **Naming**: Use full uppercase markdown naming for planning documents (e.g., `MILESTONES.md`, `TASK_NOTES.md`).
- **Archival**: When a development phase is completed and merged into production, relevant architectural decisions should be recorded in [`docs/DECISION.md`](../docs/DECISION.md) and empirical results in [`docs/CASE_STUDIES.md`](../docs/CASE_STUDIES.md).
